# 论文周报自测清单

本清单用于脚本、模板、依赖或 profile 变更后的回归检查。不采集真实论文即可验证的项目，使用本地合成输入；测试内容不得混入正式周报。

## 1. 执行范围

- 只调整说明文字时，核对命令参数、文件引用及说明与脚本的对应关系。
- 修改周期、筛选、校验或渲染实现时，执行下表相应检查；修改公共字段或模板时，补跑完整的本地校验与渲染流程。
- 实际抓取需另行检查来源和日期覆盖。请求失败、证书错误或来源未读完整，不得直接解释为“本周无相关论文”。
- 每次记录输入、命令、实际结果与未通过项。未运行、已知失败、环境阻塞分别说明，不以静态检查代替功能测试。

## 2. 回归场景

| 检查项 | 输入或操作 | 预期结果 |
|---|---|---|
| 运行环境 | 检查当前 Python 版本、时区及 `jinja2` 导入 | 满足 Python 3.9+，能读取 `Asia/Shanghai`；渲染依赖可用。抓取缺少 `certifi` 可回退系统证书，但不能忽略证书错误 |
| 周三运行 | `resolve_week.py --today 2026-09-16` | 窗口为 `2026-09-09` 至 `2026-09-15`，共7天 |
| 周末运行 | `resolve_week.py --today 2026-09-20` | 同样返回 `2026-09-09` 至 `2026-09-15`，不改为滚动7天 |
| 周二尚未结束 | `resolve_week.py --today 2026-09-15` | 按业务规则应返回 `2026-09-02` 至 `2026-09-08`；当前实现不满足，见第3节 |
| 跨年窗口 | `resolve_week.py --today 2026-01-07` | 返回 `2025-12-31` 至 `2026-01-06`，日期边界和天数正确 |
| 更换业务线 | 用临时 profile 修改 `display_name`、关键词、相关性阈值和篇数上限，传入 `--profile` | 校验与渲染采用新配置，标题和筛选结果不残留原业务线；新方向的实际抓取及迁移分析另行验证 |
| 空周 | 合法 profile 与空分析 JSONL 输入渲染 | `papers_count=0`，页面展示“本周无符合相关性标准的论文”，不生成占位论文卡片或虚构结论 |
| 归属红线 | 分别在 `summary_zh`、`key_insight`、`actionable_idea` 放入 profile 业务线名称，再仅将其放入 `inspiration` | 前三种输入校验失败；最后一种不因业务线名称被拦截。脚本匹配通过仍需人工核对论文事实与业务推断是否分开 |
| 缺项与空段 | 分别删除任一必需字段或将其设为空字符串 | 校验返回 `passed=false`，不得继续作为合格输入交付 |
| 模板套话 | 在任一分析段加入校验器禁止的模板语句 | 校验报错，修改实际分析内容后重新校验，不删掉规则绕过 |
| 筛选和篇数 | 使用分数分别高于、等于、低于阈值的记录，并构造超出上限的入选集 | 渲染按阈值、降序及上限处理；校验器拒绝超上限的入选集，不能依赖渲染截断掩盖未通过校验的输入 |
| 页面呈现 | 用已通过校验的合成输入渲染并在浏览器检查 | 标题链接指向对应原文，四段齐全、无空段，周期和篇数与输入一致；未提供顶部结论时不渲染空结论区 |

## 3. 已知限制

1. **周二窗口存在实现偏差。** `resolve_week.py` 按“不晚于今天的周二”计算，周二运行会把尚未结束的当天包含进窗口，与“最近一个已过完的周二”不符。本次仅整理说明，未修改脚本；不要把周二用例标为通过，也不要把未完整结束的周期交付为完整周报。
2. **校验器不能证明分析正确。** 当前主要检查字段存在与空值、入选数量、业务线名称及模板语句。它不验证论文真实性、完整周期覆盖或所有数字口径；空格占位、字段类型、无效链接和事实归属仍需交付前检查。
3. **渲染不等于校验。** 渲染器会过滤低分记录并截断超额记录；主流程必须先运行校验器，修正未通过项，再渲染。渲染成功不能替代来源、内容和页面检查。

## 4. 本地运行方式

以下命令从 `paper-intelligence/` 目录执行；临时测试输入另存，不覆盖正式 profile 和周报。先准备对应场景的分析 JSONL，再运行校验与渲染。

```bash
python3 scripts/resolve_week.py --today 2026-09-16
python3 scripts/resolve_week.py --today 2026-09-20
python3 scripts/resolve_week.py --today 2026-09-15
python3 scripts/resolve_week.py --today 2026-01-07

python3 scripts/validate_selection.py \
  --profile assets/profiles/customer-service.json \
  --analysis-file <临时分析.jsonl>

python3 scripts/render_report.py \
  --profile assets/profiles/customer-service.json \
  --analysis-file <临时分析.jsonl> \
  --period-start 2026-09-09 --period-end 2026-09-15 \
  --out <临时周报.html>
```

示例日期只服务于固定测试，不作为正式周报的默认周期。除预期失败的负例外，校验成功后才继续渲染；负例应核对报错原因，而不是只看进程是否退出。
